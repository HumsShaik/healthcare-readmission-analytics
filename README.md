# Healthcare Readmission Analytics

## Project Overview

This project analyzes hospital readmission patterns using the UCI Diabetes 130-US Hospitals dataset.

The goal is to build an end-to-end healthcare analytics project using SQL, Python, Machine Learning, Streamlit, Power BI, and GitHub.

## Dataset

Source: UCI Machine Learning Repository — Diabetes 130-US Hospitals for Years 1999–2008
